# Rohit Yadav portfolio

Standalone React, Vite, and Tailwind CSS v4 project.

- Run `pnpm install` to install dependencies.
- Run `pnpm dev` to start the development server. It defaults to port 8443 and accepts `PORT`.
- Run `pnpm build` to produce the static site in `dist/`.

Start UI changes in `src/App.tsx`. Global styling and Tailwind theme variables live in `src/index.css`. Use Tailwind utility classes directly in JSX and default-export components. The `@` alias resolves to `src/`.
